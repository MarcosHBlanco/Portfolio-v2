# Marcos Blanco — Developer Portfolio

My personal portfolio site, built with React and Tailwind CSS.

**Live:** [marcos-portfoliov2.vercel.app](https://marcos-portfoliov2.vercel.app)

## About

A responsive single-page portfolio showcasing my projects, background, and
skills. I'm a Computer Science student at Langara College transitioning into
software engineering after a clinical healthcare career in Brazil.

## Built with

- **React** (Vite) — component-based UI
- **Tailwind CSS** — utility-first styling
- **JavaScript (ES6+)**
- Deployed on **Vercel**

## Structure

The site is organized into About, Projects, and Contact sections with in-page
navigation. The Projects section is rendered from a structured data file
(`src/projects.js`), so adding or updating a project means editing one object
rather than touching markup.

## Running locally

```bash
git clone https://github.com/MarcosHBlanco/Portfolio-v2.git
cd Portfolio-v2/portfolio-v2
npm install
npm run dev
```
